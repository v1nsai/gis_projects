# GIS Projects
This is a mono repo that contains common scripts for pulling GIS data and creating interactive maps hosted by GitHub Pages.

# Tech Stack
- Python
- BASH
- LeafletJS
- ReactJS

# Projects
## Walkability Top 3
When looking for apartments, the top 3 things I look for are apartments, groceries and some sort of transit stop within walking distance of each other.  With these 3 things, one can at least get food and go to work without a car.  This project aims to map those 3 things using open GIS data from Fairfax County and Google for the grocery store data since I couldn't find a dataset published by Fairfax that had this info.
